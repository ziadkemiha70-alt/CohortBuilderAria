# Documentation

Ce dossier regroupe les documents destinés à comprendre, installer et utiliser le projet ARIA ODM Builder.

## Documents disponibles

| Document | Rôle |
|---|---|
| [overview_github.pdf](overview_github.pdf) | Vue d’ensemble visuelle de l’architecture et du workflow. |
| [overview_github.tex](overview_github.tex) | Source LaTeX du diaporama. |
| [documentation.tex](documentation.tex) | Documentation utilisateur détaillée. |
| [guide_execution_sql.md](guide_execution_sql.md) | Guide d’exécution des requêtes SQL depuis VS Code. |
| [scenarios.md](scenarios.md) | Scénarios utilisateur et exemples d’usage. |
| [scenarios.tex](scenarios.tex) | Source LaTeX des scénarios. |

## Ordre de lecture recommandé

```text
1. overview_github.pdf
2. README.md à la racine du dépôt
3. guide_execution_sql.md si les extractions SQL doivent être lancées
4. documentation.tex pour le détail technique
5. scenarios.md pour les cas d’usage
```

## Remarque

Les fichiers `.tex` sont les sources modifiables.  
Les fichiers `.pdf`, lorsqu’ils sont présents, sont les versions plus confortables à lire.
