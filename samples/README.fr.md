# Jeux de démonstration

Le dossier `samples/` contient des données fictives destinées à vérifier le chargement, le filtrage CIM10, l'intégration ETHOS, les temporalités et la génération des sorties.

Les fichiers de données restent communs aux deux langues. Les documents français et anglais décrivent le même jeu de test et ne nécessitent aucune copie supplémentaire des CSV, XLSX ou ZIP.

Exemples de sources attendues :

```text
traitement_patient.csv
formulaire_patient.csv
ethos_patient.csv
```

Consulter [Tests et validation](../docs/fr/tests_validation.md) pour les scénarios recommandés.
