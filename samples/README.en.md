# Demonstration datasets

The `samples/` directory contains fictitious data intended to verify loading, ICD-10 filtering, ETHOS integration, temporal assignment and output generation.

The data files are shared by both documentation languages. French and English documentation refer to the same CSV, XLSX or ZIP files; the datasets must not be duplicated by language.

Expected logical examples include:

```text
traitement_patient.csv
formulaire_patient.csv
ethos_patient.csv
```

See [Testing and validation](../docs/en/testing_validation.md) for recommended scenarios.
