# CohortBuilderAria

CohortBuilderAria uses one shared application codebase, one set of SQL scripts and one configuration structure. Only the documentation is provided in two languages.

CohortBuilderAria utilise un seul code applicatif, un seul ensemble de scripts SQL et une seule structure de configuration. Seule la documentation est proposée dans deux langues.
